## 🚀 Panduan Deploy ke GitHub Pages (Gratis & Sangat Mudah)

Anda tidak perlu memberikan password atau akun GitHub Anda. Cukup ikuti salah satu cara berikut:

### Cara 1: Mengunggah via Website GitHub (Tanpa Perlu Install Git)
1. Buka [GitHub.com](https://github.com/) dan login ke akun Anda.
2. Buat repositori baru:
   - Klik tombol **New** (atau ikon `+` di kanan atas > **New repository**).
   - Beri nama repositori, misalnya: `lssdnote`.
   - Pilih **Public**.
   - Biarkan centang README kosong, lalu klik **Create repository**.
3. Di halaman repositori baru:
   - Klik link **uploading an existing file**.
   - Tarik dan lepas (*drag and drop*) file-file dari folder ini:
     - `index.html`
     - `.nojekyll`
     - `README.md`
     - Folder `assets/` beserta isinya (`assets/images/lssd-badge.png` dan `assets/images/lssd-badge.jpg`).
   - Tulis pesan commit (misal: `Initial commit LSSD Handbook with Weapon Section`), lalu klik **Commit changes**.
4. Aktifkan **GitHub Pages**:
   - Masuk ke tab **Settings** di repositori Anda.
   - Di menu sebelah kiri, klik **Pages**.
   - Di bagian **Build and deployment** > **Branch**:
     - Ubah dari `None` menjadi **`main`** (atau `master`).
     - Pastikan foldernya **`/(root)`**.
     - Klik **Save**.
5. Tunggu sekitar 1–2 menit, GitHub akan menampilkan pesan:
   > *Your site is live at `https://<username-anda>.github.io/lssdnote/`*

---

### Cara 2: Menggunakan Git Command Line / Terminal
Jika Anda memiliki Git terpasang:
```bash
# 1. Masuk ke folder proyek
cd "C:\Users\fahri.mediansyah\.gemini\antigravity\scratch\lssdnote"

# 2. Inisialisasi Git
git init
git branch -M main

# 3. Hubungkan ke repositori GitHub Anda
git remote add origin https://github.com/<username-anda>/lssdnote.git

# 4. Tambahkan file dan commit
git add .
git commit -m "Add Weapon Classification & Authority and update LSSD Handbook"

# 5. Push ke GitHub
git push -u origin main
```
Setelah itu, buka **Settings > Pages** di repositori GitHub Anda dan pilih branch `main`.
